# Market Place

Это проект интернет-магазина, включающий фронтенд и бэкенд.

## Структура
```text
market-place/
├── store-frontend/               # Фронтенд приложения (React)
│    ├── src/                     # Исходный код фронтенда
│    ├── public/                  # Статические файлы
│    └── README.md                # Документация фронтенда
│
├── store-backend/                # Бэкенд приложения (Go)
│    ├── controllers/             # Обработчики HTTP-запросов
│    ├── database/                # Подключение к базе данных
│    ├── middleware/              # Миддлвары для проверки токенов
│    ├── models/                  # Модели базы данных
│    ├── routes/                  # Маршруты API
│    ├── utils/                   # Утилиты (например, работа с JWT)
│    └── README.md                # Документация бэкенда
│
├── .gitignore                    # Файлы и директории, игнорируемые Git
└── README.md                     # Основная документация проекта
```
