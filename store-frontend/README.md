# MarketPlace Frontend

Фронтенд-часть проекта "Маркетплейс", написана на React и предоставляет пользовательский интерфейс для взаимодействия с бэкендом через API.

---

## Стек технологий
- **React** (JavaScript-библиотека для создания интерфейсов)
- **Axios** (для выполнения HTTP-запросов к бэкенду)
- **React Router** (для маршрутизации в приложении)
- **CSS/SCSS** (для стилизации)

---

## Структура проекта

```text
store-frontend/
├── public/                       # Статические файлы
│    ├── index.html               # Основной HTML-файл для рендеринга React-приложения
│    └── favicon.ico              # Иконка сайта
│
├── src/                          # Исходный код React-приложения
│    ├── api/                     # Функции для работы с API
│    │    └── api.js              # Запросы к бэкенду (например, получение товаров, создание заказа)
│    │
│    ├── components/              # Переиспользуемые компоненты
│    │    ├── ProductCard.js      # Компонент карточки товара (название, цена, кнопка "Добавить в корзину")
│    │    ├── Cart.js             # Компонент корзины (отображение товаров, итоговая сумма)
│    │    └── Header.js           # Компонент навигационной панели (ссылки на главную, корзину)
│    │
│    ├── pages/                   # Компоненты страниц
│    │    ├── Home.js             # Главная страница (список товаров)
│    │    ├── ProductDetail.js    # Страница с подробной информацией о товаре
│    │    └── CartPage.js         # Страница корзины
│    │
│    ├── styles/                  # Стили приложения
│    │    ├── App.css             # Стили для компонента App
│    │    └── index.css           # Глобальные стили (сброс отступов, шрифты)
│    │
│    ├── assets/                  # Статические ресурсы (изображения, иконки)
│    │    └── logo.png            # Логотип приложения
│    │
│    ├── App.js                   # Корневой компонент приложения (маршрутизация и структура)
│    └── index.js                 # Точка входа приложения (рендеринг App в DOM)
│
├── package.json                  # Зависимости и скрипты проекта
├── .gitignore                    # Файлы и директории, игнорируемые Git
└── README.md                     # Документация фронтенда
